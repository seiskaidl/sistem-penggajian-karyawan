# Sistem Penggajian Karyawan — Idelia Beauty Payroll

## Deskripsi Project

Idelia Beauty Payroll merupakan aplikasi berbasis web untuk pengelolaan sistem penggajian karyawan. Project ini dikembangkan sebagai bagian dari Uji Kompetensi Analis Program.

## Fitur Utama

- Pengelolaan data karyawan
- Pengelolaan data penggajian
- Pencatatan potongan gaji
- Pengelolaan slip gaji

## Teknologi

- Laravel
- PHP
- Database sesuai konfigurasi project

## Tujuan

Project ini bertujuan menerapkan kompetensi analisis dan pengembangan sistem informasi melalui pembuatan aplikasi penggajian karyawan.

## Jenis Project

Project Individu — Uji Kompetensi Analis Program.
